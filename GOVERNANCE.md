# Governance

Household Tasks is currently maintainer-led. The maintainer is responsible for
triage, roadmap, reviews, releases, security response, and stewardship of the
configuration and storage schemas.

Decisions favor local-first behavior, Home Assistant conventions, household
privacy, backward compatibility, and testable domain logic. Significant schema
or architectural decisions should be recorded in a public issue before merge.

Consistent contributors may be invited as reviewers or maintainers. Maintainer
access requires two-factor authentication and follows least privilege. No
single contributor is entitled to acceptance of a change.
