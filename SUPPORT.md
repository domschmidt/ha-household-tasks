# Support

- Use GitHub Discussions for installation and configuration questions.
- Use the bug template for reproducible defects.
- Use the feature template for a focused new use case.
- Use private GitHub security advisories for vulnerabilities.

Before requesting help, update to the latest release, restart Home Assistant,
check the integration log, and download redacted diagnostics. Do not share
configuration exports or raw `.storage` files publicly.

This is a community project. Response times are best effort.
